What makes it different

Built on three promises

Most tools either flatter every fund or drown you in numbers. Truthfolio does neither.

🫡

Full honesty

If a fund is weak, we say so — even if it made you money. A fund that's up can still be a bad place for your money when better options exist.

🧾

Evidence-based

Every claim traces back to a real, computed number. Open any verdict to see its sources and exactly how much each one is trusted.

🧒

Explained simply

Every metric comes with an everyday-analogy explanation. “Was the bumpy ride worth it?” instead of “risk-adjusted return.”

Under the hood

For the technically curious

The verdict is produced by a transparent, auditable scoring engine — not a black box. The LLM only explains the numbers; it never invents them or overrules the score.

  • 🧭 Supervisor / orchestrator (LangGraph) coordinates focused specialist agents — quant, research, verdict, narrator — one at a time, plan-driven and auditable.
  • 📈 Deterministic quant core — returns, rolling returns, volatility, Sharpe, Sortino, drawdown — computed with NumPy/Pandas from real NAV data.
  • 🔎 On-demand web research (Tavily) → source-reliability gate → LLM extracts cited claims with inline [n] footnotes. Strict credit controls.
  • 💡 Insights specialist — a grounded "so what?" synthesis (big picture, strengths, honest watch-outs) for a fund or a whole portfolio. On-demand and cached.
  • 🎛️ Transparent weighted scoring turns metrics + peer ranks into a 0–100 health score and the Continue / Stop / Shift verdict.
  • 🔌 Provider-switchable LLM (Claude via Anthropic, or Groq) behind one factory — the whole app switches with a single env var. It only explains; it never overrules the score.
  • 🖥️ Next.js + TypeScript frontend streaming the reasoning live over Server-Sent Events. Core runs on free public data (AMFI + mfapi).

Architecture

How it's built

A supervisor coordinates focused specialist agents over free public data — and, only when you ask, the web. Deterministic where it matters; AI only where it genuinely helps.

flowchart LR

One API, one supervisor. It calls the right specialists in turn — crunch the numbers, (optionally) research the web, score the verdict, write it up — then streams the result back.

sequenceDiagram
    autonumber
    participant You
    participant Truthfolio
    participant Data as AMFI / mfapi
    You->>Truthfolio: Review this fund
    Truthfolio->>Data: Pull real NAV history
    Data-->>Truthfolio: daily NAVs
    Truthfolio->>Truthfolio: compute metrics, rank vs peers
    Truthfolio->>Truthfolio: transparent score → Continue / Stop / Shift
    Truthfolio-->>You: honest verdict + evidence (plain English)

A standard review is fully deterministic and spends zero web-search credits — the verdict is earned from real data, not guessed.
